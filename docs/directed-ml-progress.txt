== IS 400 LABELS ENOUGH? (2026-11-25) ==

learning curve for nb (cv macro f1 by training size):
  48 -> 0.50, 96 -> 0.55, 144 -> 0.58, 192 -> 0.54, 240 -> 0.57
fixable recall jumps around 0.03-0.25, theres too few fixable rows for it to settle

read: not clearly plateaued, mostly just noisy. the real problem is fixable,
only ~26 fixable rows per training fold. more general labels wont help much

plan: label more train, but targeted, not random
  - sample new questions from the ENRICHED pool (group words), thats where fixable lives
  - better: label the ones nb is least sure about (active learning)
  - aim for ~100 fixable in train, roughly +200-300 more labels
  - append to train only. test stays these 100 forever so scores stay comparable
  - rerun the learning curve after, if the curve flattens, stop labelling
